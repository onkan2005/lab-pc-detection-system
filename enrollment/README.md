# Enrollment photos (not committed)

Put one folder per student here; the folder name becomes the student's name:

```
enrollment/
├── juan_dela_cruz/
│   ├── IMG_2031.jpg
│   └── ...
└── maria/
```

- Any file names; `.jpg`, `.jpeg`, `.png` (iPhone `.HEIC` is skipped)
- About 10–30 varied photos per person (front, slight left/right, slightly up/down)
- Everything in this folder except this README is ignored by Git and Docker, because these are
  real people's faces. Get each person's consent before adding their photos.

See the main README, section "Enroll students", for the full guide.
